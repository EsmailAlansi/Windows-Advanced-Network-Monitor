# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release
- Network connection monitoring (TCP/UDP)
- Process mapping with full executable paths
- Windows service correlation for each process
- IP classification (Private/Public/Loopback/APIPA)
- DNS hostname resolution
- Network adapter throughput monitoring
- Real-time connection change detection and logging
- HTML report generation with CSS styling
- CSV report generation
- Command-line parameters for flexible usage

### Requirements
- Windows 7/8/10/11 or Windows Server 2012+
- PowerShell 5.1 or higher
- Administrator privileges (recommended)
